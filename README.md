# 🎢 Roller Coaster Exploratory Data Analysis (EDA)

## 📌 Overview

This project explores roller coaster data using Python and data analysis libraries to uncover patterns, trends, and relationships between different roller coaster characteristics.

The goal is to perform Exploratory Data Analysis (EDA), understand the dataset, identify meaningful correlations, and communicate findings through statistical summaries and visualizations.

## 🎯 Objectives

- Explore and understand the dataset.
- Clean and preprocess data for analysis.
- Identify missing values and potential data quality issues.
- Analyze statistical distributions of numerical variables.
- Investigate relationships between roller coaster speed, height, and other available attributes.
- Create visualizations to identify patterns and trends.
- Summarize findings in a structured report.

## 🛠️ Technologies Used

- **Python** — Data analysis and programming
- **Pandas** — Data manipulation and analysis
- **NumPy** — Numerical computing
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization
- **Jupyter Notebook** — Interactive analysis

## 🔍 Analysis Plan

### 1. Data Exploration
- Inspect the dataset's dimensions and structure.
- Examine column names and data types.
- Generate descriptive statistical summaries.

### 2. Data Cleaning
- Identify missing values.
- Check for duplicate records.
- Correct data types where necessary.
- Prepare the dataset for analysis.

### 3. Statistical Analysis
- Calculate summary statistics.
- Explore distributions of speed, height, and other numerical variables.
- Identify unusual values and potential outliers.

### 4. Data Visualization
- Create histograms to understand distributions.
- Use box plots to examine outliers.
- Create scatter plots to explore relationships between variables.
- Use correlation analysis to investigate linear relationships.

### 5. Insights and Conclusions
- Identify interesting patterns in the data.
- Interpret relationships between variables.
- Summarize findings and potential areas for further investigation.

## 📊 Key Questions

This project aims to investigate the following questions:

1. What are the distributions of roller coaster speeds and heights?
2. Is there a relationship between roller coaster height and speed?
3. Which roller coasters have the highest recorded speeds?
4. How do roller coaster characteristics vary across available categories?
5. What correlations exist between numerical features?
6. What interesting patterns and trends can be discovered through EDA?

The final conclusions will be based on the actual dataset and analysis results.
